## 🚀 Featured Projects

<details>
<summary><b>🖐️ SignBridge AI — Real-Time ASL/ISL Sign Language Interpreter</b></summary>
<br/>

Browser-native sign language interpreter that translates ASL and ISL gestures into text and speech in real time — no server round-trip required for inference.

| Category | Details |
|---|---|
| **Stack** | MediaPipe Hands · TensorFlow.js · Web Speech API · Transformers.js · Gemini / Claude API |
| **Scale** | Dual-mode (ASL + ISL), real-time auto-translation pipeline |
| **Performance** | Client-side inference — sub-second gesture-to-text latency |
| **Security** | Fully browser-native execution; no raw video leaves the client |
| **Impact** | Ranked 3rd of 45 teams at HackArena 2.0 Hyderabad Zonals; advanced to the Grand Finale (Top 6 of 700+ teams) |
| **Repository** | [GavaraNeha/SignBridge-AI](https://github.com/GavaraNeha) |

Built with a small team, with the majority of the core browser-AI pipeline engineered independently — including offline sentence formation via Transformers.js and an SOS gesture-detection safety feature.

</details>
